METRICS (required on every finding): set `metrics` to the function the finding is about (`function`) and the values you read from the graph for it, under the graph's own names — cognitive, complexity, loop_depth, transitive_loop_depth and param_count as numbers, linear_scan_in_loop, alloc_in_loop, recursion_in_loop and unguarded_recursion as true or false — each one you read, none you did not. A finding stands only on a number over its bar: cognitive above 15, transitive_loop_depth above 2, or linear_scan_in_loop, alloc_in_loop, recursion_in_loop or unguarded_recursion true. One with none over its bar is dropped unread, so do not report it. Set `source` to "complexity", `ruleId` to "", and `whereChecked` to the graph query you read the values with.
