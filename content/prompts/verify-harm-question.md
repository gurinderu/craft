behaviourIntended: does the code (a doc comment, a name, a test) or the PR state that the flagged behaviour is intended? It never refutes the finding; it only stops the intent-unmet harm level. harmSupported: does the code show a listed harm — its effect, who is affected, and the recovery — as stated, at a level that holds? Set confirmedHarmLevel to the worst listed level that holds (the first, or a later one when only that holds); null, with harmSupported=false, when none holds or none is listed; never name a level that is not listed. A real effect is not enough: behaviour stated as intended is a design question, not intent-unmet — with behaviourIntended=true do not confirm intent-unmet.
